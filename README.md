# rotativaFlow

Web Application interactiva para la optimización de rutinas, hábitos, entrenamiento y estudio orientada a trabajadores con horarios laboralmente rotativos.

## 🚀 Características
- **Optimización de Horarios Rotativos**: Generación automática de bloques diarios y semanales de trabajo, descanso, gimnasio y estudio.
- **Alertas de Salida (Prep & Leave Alert)**: Conteo regresivo en tiempo real y notificaciones 10 minutos antes de la hora límite de vestirse/prepararse.
- **Reubicación Automática de Cursada**: Convierte clases en vivo a bloques de estudio de grabación cuando existen solapamientos laborales.
- **Exportación iCalendar (.ICS) & Google Calendar**: Exportación de la agenda semanal para Google Calendar, Apple Calendar y Outlook.
- **Diseño Moderno & Oscuro**: Interfaz receptiva con código de colores HSL por categoría, glassmorphism y persistencia en LocalStorage.

## 🛠️ Tecnologías
- **React 19**
- **TypeScript**
- **Vite**
- **Tailwind CSS v4**
- **Lucide React**

## 💻 Desarrollo Local
```bash
npm install
npm run dev
```

## 🌐 Deploy en Vercel
Este proyecto está configurado para desplegarse directamente en **Vercel** como una aplicación Vite + React estática.
